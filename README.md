# Tech Recruiter Portfolio

Meu primeiro projeto no GitHub: um portfólio responsivo para apresentar minha trajetória em Tecnologia e Recrutamento & Seleção Tech.

## Sobre o projeto

O projeto foi desenvolvido com HTML, CSS e JavaScript puro, sem frameworks. Além da apresentação profissional, inclui uma calculadora demonstrativa de aderência de candidatos.

## Funcionalidades

- Layout responsivo
- Menu adaptado para dispositivos móveis
- Seções de apresentação, atuação e contato
- Cards de especialidades
- Calculadora interativa de aderência
- Atualização automática do ano no rodapé
- Estrutura simples para publicação no GitHub Pages

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Como executar localmente

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server no Visual Studio Code.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos deste projeto.
3. Acesse `Settings`.
4. Clique em `Pages`.
5. Em `Build and deployment`, escolha `Deploy from a branch`.
6. Selecione a branch `main` e a pasta `/root`.
7. Salve e aguarde a publicação.

## Personalização recomendada

Antes de publicar:

- Substitua o link genérico do LinkedIn pelo seu perfil.
- Revise o número do WhatsApp.
- Ajuste os números e indicadores profissionais.
- Acrescente seus projetos, artigos ou cases.
- Inclua uma foto profissional, caso deseje.
